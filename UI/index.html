Discord / Voice Chat Tip

For cleaner program audio in Discord, disable Noise Suppression, Echo Cancellation, & Automatic Gain Control.

These automatic voice processing features can make the routed audio muffled, distorted, or choppy.

ProgramMic was designed for use in apps and games without these features.
